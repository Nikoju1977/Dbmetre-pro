Dbmetre-pro

Analyseur spectral, mesure dBFS et enregistrement microphone.

Premiers pas

  1. Autorisez le microphone après avoir vérifié votre périphérique d'entrée.
  2. Démarrez une mesure, puis consultez les niveaux dBFS et le spectre.
  3. Arrêtez la capture et exportez les données si l'option est proposée.

Avant de commencer

Pour entendre le son, appuyez sur un bouton audio dans la page ; le navigateur peut bloquer l'audio automatique.

Une valeur dBFS n'est pas une mesure certifiée de pression acoustique dB SPL.

En cas de problème

En cas de page vide ou d'erreur : rechargez une fois, vérifiez la connexion et les permissions ; sur une PWA déjà installée, fermez-la puis rouvrez-la pour actualiser son cache. Consultez le dépôt GitHub si le problème persiste.
